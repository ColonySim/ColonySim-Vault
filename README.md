# ColonySim · Валт

Валт проекта симулятора колонии. В нём хранятся исходные записи, редактура, структурированные материалы, справочник упоминаний и промпты исследований.

Откройте папку [ObsidianVault](ObsidianVault/) в Obsidian. Правила работы с материалами находятся в [AGENTS.md](AGENTS.md) и [AI/WORKFLOW.md](AI/WORKFLOW.md).

## История заметок

В заметках сохранены исходные SHA и пути для ссылок на версии. Для просмотра версии в этом репозитории найдите старый SHA в [таблице соответствий](commit-map.tsv) и подставьте новый SHA в `git show <новый SHA>:<путь>`.
